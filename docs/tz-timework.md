Сохрани архитектрурные схемы C4 · L1 и C4 · L2 внутри поекта в формате  .drawio

Задача: Оценка реализации проекта ОРИОН, оценка поверхностная, не учитывающая затраты на развертывание инфраструктуры и дизайн
- Для оценки будем использовать еденицы измерения: человеко/день
    - далее сокращенно по тексту используем абривиатуру ч/д
    - это подразумевает под собой 8-ми часовой рабочий день

Команда для реализации:
- Frontend разработчик уровня middle+
- Backend разработчик уровня middle+
- QA-manual уровня middle+
- Бизнес-аналитик уровня middle+

Все члены команды имеют опыт работы со стеком технолгий используемый на проекте.

Твое задание взять за основу трудоемкость реализации эталонных задач и масштабировать это чтобы вычислить какое приблизительное время в ч/д потребуется для реализации этого проекта

Эталонные задачи оценку которых нужно взять за дальнейший расчет.
Задачи:
    - Создание балванки микросервиса front или back 
        - ОБщие трудозатраты: 1 ч/д
        - Участники:
            - Frontend разработчик или Backend разработчик: 0.8 ч/д
            - QA-manual: 0.2 ч/д
    - Подключение в backend микросервисе EF core для работы с БД
        - ОБщие трудозатраты: 1 ч/д
        - Участники:
            - Backend разработчик: 0.8 ч/д
            - QA-manual: 0.2 ч/д
    - Создание api метода в backend микросервисе который вызывает уже существующий метод в слое репозитория
        - ОБщие трудозатраты: 1 ч/д
        - Участники:
            - Backend разработчик: 0.6 ч/д
            - QA-manual: 0.2 ч/д
            - Бизнес-аналитик: 0.2 ч/д
    - Создание api метода в backend микросервисе который вызывает метод в слое репозитория, который тоже нужно создать
        - ОБщие трудозатраты: 2 ч/д
        - Участники:
            - Backend разработчик: 1 ч/д
            - QA-manual: 0.6 ч/д
            - Бизнес-аналитик: 0.4 ч/д
    - Создание простой модлеи данных, около 20 полей, для последующего создания миграции через EF core
        - ОБщие трудозатраты: 2 ч/д
        - Участники:
            - Бизнес-аналитик: 0.4 ч/д
            - Backend разработчик: 1 ч/д
            - QA-manual: 0.6 ч/д
    - Создание на фронте окна ввода данных, порядка 20 полей и вызов запроса на backend для передачи данных
        - ОБщие трудозатраты: 2 ч/д
        - Участники:
            - Бизнес-аналитик: 0.4 ч/д
            - Frontend разработчик: 1 ч/д
            - QA-manual: 0.6 ч/д
    - Создание на backend фоновой задачи для боработки данных из таблиц и последующей их отправки по api или через брокер сообщений
        - ОБщие трудозатраты: 3 ч/д
        - Участники:
            - Бизнес-аналитик: 0.5 ч/д
            - Frontend разработчик: 1.7 ч/д
            - QA-manual: 0.8 ч/
    - Создание на backend интеграции по api с другим микросервисом
        - ОБщие трудозатраты: 2 ч/д
        - Участники:
            - Бизнес-аналитик: 0.4 ч/д
            - Frontend разработчик: 1 ч/д
            - QA-manual: 0.6 ч/д
    - Создание на backend интеграции через брокер сообщений с другим микросервисом
        - ОБщие трудозатраты: 4 ч/д
        - Участники:
